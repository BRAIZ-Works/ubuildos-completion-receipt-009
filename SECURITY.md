# Security

The public build is a static client-side demonstration with no authentication, backend, or credential requirement.

Security boundaries:
- no secrets are required by the runtime;
- no external network integration is used by the product;
- no user-entered data is transmitted by the included code;
- sample data is synthetic;
- deployment credentials, producer evidence, and independent-review internals are not part of the public projection.

No security contact channel is asserted by this artifact.
